         - Line 1: `Checkpoint #{ckpt_idx}/{total_ckpts} | Step: {step:,}/{total_steps:,} ({pct:.1f}%)`.

         - Initializes gym environment with `render_mode="rgb_array"`.
         - Resets environment with `seed`.
         - For each step up to `max_steps`:
           - Obtains rendered RGB frame.
           - Evaluates deterministic action `action = agent.select_action(state, deterministic=True)`.
           - Computes critic Q-mean from `agent.critic(state_t, action_t)`.
           - Steps environment; extracts forward velocity ($v_x$) from `info.get('x_velocity')` or unwrapped data.
           - Applies HUD overlay if `overlay=True`.
           - Accumulates telemetry dict (`frames`, `velocities`, `rewards`, `cumulative_returns`, `actions`, `q_means`).
         - Returns telemetry dictionary.
