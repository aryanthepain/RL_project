<objective>
Implement the end-to-end HalfCheetah policy progression runner and independent background execution capability:
1. Orchestrator script (`scripts/run_halfcheetah_progression.py`) automating:
   - 10,000-step training with checkpointing every 100 steps (producing 100 checkpoints).
   - 15–20s (500-frame) rollouts for all 100 checkpoints with diagnostic HUD overlays saved to `videos/checkpoints/`.
   - Synchronized 6-way 2x3 grid comparison video of checkpoints #1, #20, #40, #60, #80, #100.
   - Master chronological montage video stitching all 100 checkpoints end-to-end.
   - 4-panel behavioral diagnostics figure in `results/`.
2. Detached process launcher (`scripts/launch_progression_background.ps1`) executing the run in a detached background terminal with unbuffered output logged to `logs/progression_generation.log`, allowing the user and agent to immediately proceed with Phase 6 without blocking.
3. Smoke-test mode (`--smoke-test`) for automated regression testing.
4. Comprehensive test suite in `tests/test_progression_runner.py` and documentation in `docs/progression_visualization.md`.

Output: `scripts/run_halfcheetah_progression.py`, `scripts/launch_progression_background.ps1`, `tests/test_progression_runner.py`, and `docs/progression_visualization.md`.
</objective>

    1. Create `scripts/run_halfcheetah_progression.py`:
       - CLI arguments:
         - `--total-timesteps`: Total training steps (default 10,000).
         - `--checkpoint-freq`: Timestep interval between checkpoints (default 100).
         - `--eval-frames`: Frames per checkpoint evaluation rollout (default 500, ~16.6s at 30 fps).
         - `--seed`: Base random seed (default 42).
         - `--output-dir`: Base directory for videos (default `videos/`).
         - `--skip-train`: Skip training and evaluate existing checkpoints in `--checkpoint-dir`.
         - `--checkpoint-dir`: Directory containing checkpoints.
         - `--detach`: Spawn in background process and exit immediate parent.
         - `--smoke-test`: Fast verification mode (runs 200 steps, saves 2 checkpoints, rolls out 10 frames).
       - Workflow:
         - Step A: Train agent or locate existing checkpoints.
         - Step B: Iterate over all checkpoints in numeric step order. Rollout each checkpoint with `rollout_checkpoint_with_telemetry` and stream save to `videos/checkpoints/ckpt_{step:05d}.mp4`.
         - Step C: Extract the 6 milestone checkpoints (#1, #20, #40, #60, #80, #100) and generate synchronized 2x3 grid video `videos/halfcheetah_6way_grid.mp4`.
         - Step D: Concatenate all 100 videos into `videos/halfcheetah_progression_montage.mp4`.
         - Step E: Generate diagnostic plots in `results/halfcheetah_progression_diagnostics.png`.
    2. Create `scripts/launch_progression_background.ps1`:
       - PowerShell launcher script that:
         - Creates `logs/` directory.
         - Spawns `python -u scripts/run_halfcheetah_progression.py "$@"` using `Start-Process` detached with stdout and stderr redirected to `logs/progression_generation.log`.
         - Prints process ID and instructions on how to monitor (`Get-Content -Wait logs/progression_generation.log`).
    3. Create `tests/test_progression_runner.py`:
       - Tests argument parser and configuration builder.
       - Tests end-to-end smoke test mode with temporary directories.
