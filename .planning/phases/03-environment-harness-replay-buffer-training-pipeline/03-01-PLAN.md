  <action>
    Create `src/tqc/replay_buffer.py`.
    Implement `ReplayBuffer`:
    - `__init__(state_dim: int, action_dim: int, capacity: int = 1_000_000, device: str = "cpu")`:
      - Pre-allocate contiguous NumPy arrays:
        - `states`: `np.empty((capacity, state_dim), dtype=np.float32)`
        - `actions`: `np.empty((capacity, action_dim), dtype=np.float32)`
        - `rewards`: `np.empty((capacity, 1), dtype=np.float32)`
        - `next_states`: `np.empty((capacity, state_dim), dtype=np.float32)`
        - `dones`: `np.empty((capacity, 1), dtype=np.float32)`
      - Initialize circular index pointer `ptr = 0`, current elements count `size = 0`.
    - `add(state, action, reward, next_state, done)`:
      - Store transition at current `ptr`.
      - Increment `ptr = (ptr + 1) % capacity`.
      - Update `size = min(size + 1, capacity)`.
    - `sample(batch_size: int) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor]`:
      - Sample random integer indices in `[0, size)` using `np.random.randint`.
      - Convert sampled slices to `torch.FloatTensor` on `self.device`.
      - Return `(states, actions, rewards, next_states, dones)`.
    - `__len__()`: returns current `size`.
    Write unit tests in `tests/test_buffer.py` testing capacity limits, circular overwrite pointer behavior, batch tensor shapes, types, and device mapping.
  </action>

  </verify>
