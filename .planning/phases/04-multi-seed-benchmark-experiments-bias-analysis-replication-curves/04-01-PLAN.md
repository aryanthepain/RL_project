  <action>
    Create `src/tqc/bias_analysis.py`.
    Implement `compute_overestimation_bias(agent, env, n_samples=50, gamma=0.99, max_steps=1000)`:
      - Samples states from policy execution.
      - For each state $s$:
        - Computes deterministic policy action $a = \pi(s)$.
        - Evaluates critic predicted Q-value: $\hat{Q}(s, a)$ (average of predicted quantiles).
        - Executes Monte Carlo rollout from current environment state under policy $\pi$ to trajectory termination or `max_steps`, accumulating discounted return $G = \sum_{t=0}^{H-1} \gamma^t r_t$.
        - Computes bias $\Delta = \hat{Q}(s, a) - G$.
      - Returns dictionary with:
        - `mean_predicted_q`: float
        - `mean_true_return`: float
        - `mean_bias`: float
        - `std_bias`: float
        - `q_predictions`: list of floats
        - `mc_returns`: list of floats
      - Provides `save_bias_report(bias_dict, output_path)` saving summary to JSON.
    Write unit tests in `tests/test_bias.py` using synthetic/mock agents and environments with known rewards to verify that bias calculation matches mathematical expectation exactly.
  </action>
