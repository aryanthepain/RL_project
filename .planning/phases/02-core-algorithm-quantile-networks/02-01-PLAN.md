    Create `src/tqc/truncation.py`.
    Implement:
    1. `quantile_huber_loss(predictions, targets, tau, kappa=1.0)`:
       - `predictions`: shape `(B, n_quantiles, 1)`
       - `targets`: shape `(B, 1, n_target_quantiles)`
       - Compute pairwise error $u = \text{targets} - \text{predictions}$.
       - Apply Huber loss $\mathcal{L}_\kappa(u)$.
       - Weight by $|\tau - \mathbb{I}(u < 0)| / \kappa$.
       - Return scalar loss averaged over batch, quantiles, and target atoms.
    2. `truncate_quantiles(target_quantiles, drop_top=5)`:
       - `target_quantiles`: shape `(B, n_critics, n_quantiles)` (e.g. `(B, 5, 25)`).
       - Reshape/flatten ensemble atoms to `(B, n_critics * n_quantiles)` (125 atoms).
       - Sort along atom dimension in ascending order.
       - Truncate top $d$ atoms: return `sorted_quantiles[:, :n_total - drop_top]` (retaining $125 - d$ atoms).
    Write unit tests in `tests/test_truncation.py` verifying exact loss calculation against known manual values, and verifying truncation sorts and discards top $d$ values correctly.
