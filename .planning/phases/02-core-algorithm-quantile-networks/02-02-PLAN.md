    Create `src/tqc/agent.py` implementing `TQCAgent`:
    - Initialization:
      - `state_dim`, `action_dim`, `hidden_dim=512`, `n_critics=5`, `n_quantiles=25`, `drop_top=5`, `gamma=0.99`, `tau=0.005`, `lr=3e-4`, `target_entropy=None` (defaults to `-action_dim`), `device="cpu"`.
      - Initialize `actor` and Adam optimizer.
      - Initialize `critic` and `critic_target` (deep copy of critic, evaluation mode).
      - Initialize `log_alpha = torch.zeros(1, requires_grad=True, device=device)` and Adam optimizer.
    - Methods:
      - `select_action(state, deterministic=False)`: converts numpy state to tensor, evaluates actor, returns numpy action in [-1, 1].
      - `update(batch)`:
        - Unpack `states`, `actions`, `rewards`, `next_states`, `dones` (tensors).
        - Step 1: Target value calculation:
          - Sample `next_actions`, `next_log_probs` from actor on `next_states`.
          - Forward pass `critic_target(next_states, next_actions)`.
          - Apply `truncate_quantiles(target_quantiles, drop_top=self.drop_top)`.
          - Shift by `rewards + gamma * (1 - dones) * (truncated_atoms - alpha * next_log_probs)`.
        - Step 2: Critic update:
          - Forward pass `critic(states, actions)`.
          - Compute pairwise quantile Huber loss for each critic against targets.
          - Backward and step critic optimizer.
        - Step 3: Actor update:
          - Sample new actions and log-probs from actor on `states`.
          - Evaluate `critic(states, new_actions)` and compute mean over all critics and quantiles: $Q_{\text{mean}}$.
          - Compute actor loss: $\mathbb{E}[\alpha \log \pi - Q_{\text{mean}}]$.
          - Backward and step actor optimizer.
        - Step 4: Alpha update:
          - Compute temperature loss: $-\log \alpha \cdot (\log \pi + \bar{\mathcal{H}})$.detach().
          - Backward and step alpha optimizer.
        - Step 5: Polyak target network update:
          - For each target param $\bar{\theta}$ and online param $\theta$: $\bar{\theta} \leftarrow \tau \theta + (1 - \tau) \bar{\theta}$.
        - Return dictionary with training metrics (`critic_loss`, `actor_loss`, `alpha_loss`, `alpha`, `mean_target_q`, `mean_pred_q`).
      - `save(filepath)` and `load(filepath)`: save/load actor, critic, critic_target, log_alpha, and optimizers.
    Update `src/tqc/__init__.py` to export `TQCAgent`, `Actor`, `CriticEnsemble`, `quantile_huber_loss`, and `truncate_quantiles`.
